# OPlusKeyControl

Customize the hardware buttons on OnePlus 15 to control the flashlight, launch
apps, open shortcuts and record audio with familiar button gestures.

[Tiếng Việt](README.md) · [Download APK](https://github.com/quyetbkhoa/OPlusKeyControl/releases)

## Button mappings

- **Plus button:** assign separate actions to single press, double press, triple press and long press.
- **Power button:** assign actions to double press and triple press.
- **Button combinations:** Plus + Volume Up, Plus + Volume Down and Plus + Power.
- **Independent controls:** enable or disable individual mappings or use the master switch.
- **Adjustable timing:** customize double-press, long-press and combination thresholds.

Power gestures and advanced combinations belong to the experimental runtime
build. Availability depends on firmware and the connection status shown in the app.

## Quick actions

| Action | Features |
| --- | --- |
| Flashlight | Turn on, turn off or toggle with a button gesture |
| Apps | Launch a selected app |
| In-app shortcuts | Select and launch a specific Activity after a confirmation test |
| Camera | Quickly open the phone’s stock camera |
| Audio recording | Start/stop MP3 recording, set an automatic stop time and stop from the notification |

## Feedback and utilities

- **Vibration feedback:** optional recognition feedback; long press can vibrate
  as soon as the threshold is reached, before the button is released.
- **Action tests:** try an action inside the app before assigning it to a button.
- **Recording history:** browse MP3 recordings and open them for playback.
- **Inspector:** inspect the current app and Activity to find the function to open.
- **Automatic reconnection:** restore the input connection after the system terminates the app process.

## Settings and interface

- Dark Material 3 interface with Vietnamese and English support.
- Mappings grouped by Plus, Power and button combinations.
- Searchable app picker with icons and Activity selection.
- JSON configuration backup and restore.
- Connection, permission and per-action readiness indicators.
- **Disable now** button and Quick Settings tile to turn off remapping.
