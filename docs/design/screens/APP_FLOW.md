# Screen briefs

- Keys: choose physical key, read actual mappings/status, edit or add. Primary
  CTA add rule. Master and connection visible above key filters. Empty state is
  an invitation to assign, not a fake ready rule. Supports master off, missing
  backend, disabled/unverified rules, schedule gaps, long package labels.
- Rule editor: one task, one page. Trigger and action first; schedule/priority
  expand in place. Enable and Save reflect unchanged capability/conflict gates.
  Test remains an explicit confirmation. Back exits form or picker, no automatic
  persistence. Bottom actions stay above IME/navigation bars.
- Picker: search first, system/advanced filter next, content count and actual
  lists. Protect disabled/protected activities and preserve root internal
  activity selection. Loading/error/empty states localized.
- Tools: grouped settings (connection, background, timing), content (recordings,
  backup), utilities (action test, inspector, diagnostics), about. List rows
  rather than a screen of unrelated giant tiles. All original callbacks kept.
- Inspector: align native overlay colors/spacing with blue utility identity;
  leave tree capture, permissions, file saving and lifecycle unchanged.

Narrow phones use flowing chips and stacked labels; wider windows center main
content and use a navigation rail. All content scrolls safely at large fonts.
